# Налаштування зберігання контактів на GitHub Pages

Цей файл містить інструкції для налаштування зберігання контактів у хмарі, щоб вони зберігалися навіть після хостингу на GitHub Pages.

## Як це працює

За замовчуванням контакти зберігаються в `localStorage` браузера (локально). Для зберігання контактів у хмарі (щоб вони були доступні на GitHub Pages), використовується безкоштовний сервіс **JSONBin.io**.

## Крок 1: Реєстрація на JSONBin.io

1. Перейдіть на https://jsonbin.io
2. Натисніть "Sign Up" (безкоштовна реєстрація)
3. Зареєструйтесь через email або GitHub

## Крок 2: Створення Bin

1. Після входу натисніть "Create Bin"
2. Відкриється редактор JSON
3. Вставте наступний початковий контент:
```json
{
  "contacts": []
}
```
4. Натисніть "Save"
5. Скопіюйте **Bin ID** з URL або з інформації про bin (виглядає як: `507f1f77bcf86cd799439011`)

## Крок 3: Налаштування у вашому коді

1. Відкрийте файл `js/script.js`
2. Знайдіть секцію `STORAGE_CONFIG` (приблизно на рядку 96)
3. Змініть конфігурацію:
```javascript
const STORAGE_CONFIG = {
  useCloudStorage: true, // Змініть на true
  jsonBinId: 'ВАШ_BIN_ID_ТУТ', // Вставте сюди ваш Bin ID
  jsonBinApiKey: '', // Опціонально: для приватних bins
  githubToken: '', // Опціонально: для GitHub Gist
  gistId: '', // Опціонально: для GitHub Gist
  fallbackToLocal: true
};
```

## Крок 4: (Опціонально) Налаштування приватного Bin

Якщо ви хочете зробити ваш Bin приватним:

1. На JSONBin.io перейдіть до налаштувань вашого Bin
2. Скопіюйте ваш **X-Master-Key** (API ключ)
3. Вставте його в `jsonBinApiKey` в `STORAGE_CONFIG`

**Примітка:** Без API ключа ваш Bin буде публічним (читання/запис для всіх, хто знає ID).

## Як працює зберігання

- **localStorage**: Контакти завжди зберігаються локально як резервна копія
- **JSONBin.io**: Контакти синхронізуються з хмарою, якщо налаштовано
- **Автоматичне резервування**: Якщо хмарне зберігання недоступне, використовується localStorage

## Перевірка

1. Заповніть форму контакту на сайті
2. Перевірте, що контакт з'явився в списку
3. Відкрийте JSONBin.io та перевірте, що контакт зберігся там
4. Очистіть localStorage у браузері і перезавантажте сторінку
5. Контакт повинен завантажитися з хмари

## Важливо

- Безкоштовний план JSONBin.io має обмеження на кількість запитів
- Для продакшн використання рекомендовано створити власний backend або використати платний план
- Контакти завжди зберігаються в localStorage як резервна копія

## Альтернативи

Якщо ви хочете використати інший сервіс:

1. **GitHub Gist API** - потрібен GitHub токен
2. **Firebase Realtime Database** - безкоштовний план доступний
3. **Supabase** - безкоштовний PostgreSQL backend
4. **Власний backend** - Node.js, Python, PHP тощо

Для інтеграції іншого сервісу змініть функції `saveToCloud()` та `loadFromCloud()` в `js/script.js`.
